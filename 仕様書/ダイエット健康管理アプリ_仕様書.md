# ダイエット健康管理アプリ 仕様書

**アプリ名**: ダイエット健康管理  
**バージョン**: v1.0.0  
**最終更新日**: 2026年4月22日  

---

## 1. 概要

食事・体重・運動・お通じを記録し、AIが健康アドバイスを提供するWebアプリケーション。  
LINE LIFF（LINE Front-end Framework）を利用し、LINEのWebView内で動作する。データはGoogle Apps Script（GAS）を経由してGoogleスプレッドシートに保存。食事写真はGoogle Driveに保存。AIアドバイス機能はGASからGemini APIを呼び出すことで実現する。

## 4. データフロー

### 4.1 記録登録フロー

```
1. ユーザーがLINEアプリでLIFFを開く
2. LIFF SDK でLINEログイン → プロフィール（userId, displayName）取得
3. GASに「register」アクションを送信 → ユーザー自動登録
4. 記録種別（食事／体重／運動／お通じ）を選択
5. 各フォームに入力（食事の場合は写真も撮影/選択）
6. 「記録する」ボタン押下
7. GASに「uploadRecord」アクションを送信（写真はBase64エンコード）
8. GAS側でスプレッドシートに記録＆写真をGoogle Driveに保存
9. 成功レスポンスを受けてページリロード
```

### 4.2 データ参照フロー

```
1. 「履歴」または「サマリー」タブをタップ
2. GASに「getRecords」アクションを送信
3. 全データを取得し、フロントエンドでフィルタリング
4. 履歴：リスト形式で表示 / サマリー：グラフ＋統計カードで可視化
```

### 4.3 AIアドバイスフロー

```
1. サマリータブで「AIに分析してもらう」ボタンをタップ
2. フロントエンドが直近30件の記録データをGASに送信
3. GASがデータを整形し、Gemini APIへプロンプト送信
4. Gemini APIからアドバイステキストを受信
5. フロントエンドに返してアドバイスを表示
```

## 5. 画面仕様

### 5.1 記録タブ

記録種別を4つのボタンで切り替え。選択した種別に応じてフォームが動的に切り替わる。

| 記録種別 | アイコン | 入力項目 |
|---------|---------|---------|
| 食事 | 🍽️ | 食事タイプ（朝食/昼食/夕食/間食/プロテイン/飲み物/その他）・写真（最大3枚）・メモ |
| 体重 | ⚖️ | 体重(kg)・体脂肪率(%)・筋肉量(kg)・内臓脂肪・身長(初回のみ)・BMI自動計算・メモ |
| 運動 | 💪 | 運動種類・時間(分)・距離(km)・メモ |
| お通じ | 🌿 | あり/なしのトグル・メモ |

**食事タイプ一覧:**  
朝食 / 昼食 / 夕食 / 間食 / プロテイン / 飲み物 / その他

**運動種類一覧:**  
ジム（筋トレ）/ ウォーキング / ランニング / ヨガ・ストレッチ / 水泳 / サイクリング / 有酸素運動 / その他

**BMI自動計算:**  
体重入力時に自動計算。身長はlocalStorageに保存（初回入力後は自動入力）。

### 5.2 履歴タブ

| 項目 | 仕様 |
|------|------|
| フィルタ | 記録種別 / ユーザー / 年（2025〜2030） / 月（1〜12） |

| リスト | 種別バッジ・内容・日付・ユーザー名・写真ボタンを表示 |
| 並び順 | 日付降順（新しい順） |
| 写真表示 | ボタンタップで別タブに写真を表示 |

### 5.3 サマリータブ

| 項目 | 仕様 |
|------|------|
| フィルタ | ユーザー / 年 / 月 |
| 統計カード（4枚） | 直近の体重・直近の体脂肪率・今月の運動回数・今月のお通じ率 |
| 体重推移グラフ（折れ線） | フィルタ期間の体重の変化を時系列で表示 |
| 運動種別グラフ（ドーナツ） | フィルタ期間の運動種別の割合を表示 |

## 6. API仕様（GAS連携）

**エンドポイント:**  
`https://script.google.com/macros/s/[デプロイID]/exec`

**通信方式:** POST（JSON）

### 6.1 アクション一覧

| アクション | 説明 | リクエストデータ | レスポンス |
|-----------|------|----------------|-----------|
| `register` | ユーザー登録（初回自動） | `{ userId, displayName }` | `{ status: "success" }` |
| `getUsers` | 登録ユーザー一覧取得 | `{}` | `{ result: [{ lineId, name }] }` |
| `uploadRecord` | 健康記録を登録 | 下記参照 | `{ status: "success" }` |
| `getRecords` | 全記録データ取得 | `{}` | `{ result: [...] }` |
| `getAIAdvice` | AI健康アドバイス取得 | `{ lineId, recentRecords }` | `{ advice: "..." }` |

## 7. GASコード（バックエンド全文）

Google Apps Scriptエディタに以下のコードを貼り付ける。

```javascript
const SHEET_ID = "YOUR_SPREADSHEET_ID";        // スプレッドシートID
const DRIVE_FOLDER_ID = "YOUR_DRIVE_FOLDER_ID"; // 写真保存フォルダID
const GEMINI_API_KEY = "YOUR_GEMINI_API_KEY";   // Gemini APIキー

function doPost(e) {
  const body = JSON.parse(e.postData.contents);
  const { action, data } = body;

  let result;
  switch (action) {
    case "register":     result = registerUser(data);  break;
    case "getUsers":     result = getUsers();           break;
    case "uploadRecord": result = uploadRecord(data);  break;
    case "getRecords":   result = getRecords();         break;
    case "getAIAdvice":  result = getAIAdvice(data);   break;
    default: result = { status: "error", message: "Unknown action" };
  }

  return ContentService
    .createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

// ---- ユーザー登録 ----
function registerUser(data) {
  const ss = SpreadsheetApp.openById(SHEET_ID);
  let sheet = ss.getSheetByName("ユーザー");
  if (!sheet) {
    sheet = ss.insertSheet("ユーザー");
    sheet.appendRow(["lineId", "name", "createdAt"]);
  }
  const values = sheet.getDataRange().getValues();
  const exists = values.some(row => row[0] === data.userId);
  if (!exists) {
    sheet.appendRow([data.userId, data.displayName, new Date().toISOString()]);
  }
  return { status: "success" };
}

// ---- ユーザー一覧取得 ----
function getUsers() {
  const ss = SpreadsheetApp.openById(SHEET_ID);
  const sheet = ss.getSheetByName("ユーザー");
  if (!sheet) return { result: [] };
  const values = sheet.getDataRange().getValues().slice(1);
  return { result: values.map(r => ({ lineId: r[0], name: r[1] })) };
}

// ---- 記録を登録 ----
function uploadRecord(data) {
  const ss = SpreadsheetApp.openById(SHEET_ID);
  let sheet = ss.getSheetByName("記録");
  if (!sheet) {
    sheet = ss.insertSheet("記録");
    sheet.appendRow([
      "date", "lineId", "userName", "recordType", "subType",
      "weight", "bodyFat", "muscleMass", "visceralFat",
      "duration", "distance", "memo", "imageUrls", "createdAt"
    ]);
  }

  // 食事写真をGoogle Driveにアップロード
  let imageUrls = [];
  if (data.imageBlobs && data.imageBlobs.length > 0) {
    const folder = DriveApp.getFolderById(DRIVE_FOLDER_ID);
    data.imageBlobs.forEach((blob, i) => {
      try {
        const base64Data = blob.replace(/^data:image\/(png|jpeg|jpg|gif|webp);base64,/, '');
        const byteArray = Utilities.base64Decode(base64Data);
        const file = folder.createFile(
          Utilities.newBlob(byteArray, 'image/jpeg', `diet_${Date.now()}_${i}.jpg`)
        );
        file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
        imageUrls.push('https://drive.google.com/uc?export=view&id=' + file.getId());
      } catch (err) {
        console.error("画像アップロードエラー:", err);
      }
    });
  }

  const ex = data.extraData || {};
  sheet.appendRow([
    data.date,
    data.lineId,
    data.userName,
    data.recordType,
    data.subType || "",
    ex.weight      !== null && ex.weight      !== undefined ? ex.weight      : "",
    ex.bodyFat     !== null && ex.bodyFat     !== undefined ? ex.bodyFat     : "",
    ex.muscleMass  !== null && ex.muscleMass  !== undefined ? ex.muscleMass  : "",
    ex.visceralFat !== null && ex.visceralFat !== undefined ? ex.visceralFat : "",
    ex.duration    !== null && ex.duration    !== undefined ? ex.duration    : "",
    ex.distance    !== null && ex.distance    !== undefined ? ex.distance    : "",
    data.memo || "",
    imageUrls.join(","),
    new Date().toISOString()
  ]);

  return { status: "success" };
}

// ---- 全記録取得 ----
function getRecords() {
  const ss = SpreadsheetApp.openById(SHEET_ID);
  const sheet = ss.getSheetByName("記録");
  if (!sheet) return { result: [] };

  const values = sheet.getDataRange().getValues().slice(1);
  const result = values.map(r => ({
    date:       r[0] instanceof Date ? Utilities.formatDate(r[0], "Asia/Tokyo", "yyyy-MM-dd") : r[0],
    lineId:     r[1],
    userName:   r[2],
    recordType: r[3],
    subType:    r[4],
    extraData: {
      weight:      r[5]  !== "" ? Number(r[5])  : null,
      bodyFat:     r[6]  !== "" ? Number(r[6])  : null,
      muscleMass:  r[7]  !== "" ? Number(r[7])  : null,
      visceralFat: r[8]  !== "" ? Number(r[8])  : null,
      duration:    r[9]  !== "" ? Number(r[9])  : null,
      distance:    r[10] !== "" ? Number(r[10]) : null
    },
    memo:       r[11],
    imageUrls:  r[12] ? r[12].split(",").filter(u => u) : []
  }));

  return { result };
}

// ---- AI健康アドバイス ----
function getAIAdvice(data) {
  const records = data.recentRecords || [];

  let context = "以下は直近の健康記録データです:\n\n";
  records.forEach(r => {
    if (r.recordType === "体重") {
      const w   = r.extraData?.weight      ? `体重 ${r.extraData.weight}kg`      : "";
      const bf  = r.extraData?.bodyFat     ? `体脂肪率 ${r.extraData.bodyFat}%`  : "";
      const mm  = r.extraData?.muscleMass  ? `筋肉量 ${r.extraData.muscleMass}kg`: "";
      context += `[${r.date}] 体重測定: ${[w, bf, mm].filter(Boolean).join(", ")}\n`;
    } else if (r.recordType === "運動") {
      const dur  = r.extraData?.duration ? `${r.extraData.duration}分` : "";
      const dist = r.extraData?.distance ? `${r.extraData.distance}km` : "";
      context += `[${r.date}] 運動: ${r.subType} ${[dur, dist].filter(Boolean).join(" ")}\n`;
    } else if (r.recordType === "食事") {
      context += `[${r.date}] 食事(${r.subType}): ${r.memo || "写真のみ"}\n`;
    } else if (r.recordType === "お通じ") {
      context += `[${r.date}] お通じ: ${r.subType}\n`;
    }
  });

  const prompt = `あなたはダイエットと健康管理の専門家AIです。
以下の健康記録を分析し、具体的で実践的なアドバイスを提供してください。

${context}

以下の観点でアドバイスをお願いします:
1. 体重変化のトレンド（増減のパターン）
2. 食生活への具体的な提案
3. 運動習慣への提案
4. お通じの状態から見る腸内環境
5. 今週すぐ取り組める具体的な1アクション

親しみやすく励ます口調で、400文字以内でまとめてください。`;

  try {
    const response = UrlFetchApp.fetch(
      `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${GEMINI_API_KEY}`,
      {
        method: "post",
        contentType: "application/json",
        payload: JSON.stringify({
          contents: [{ parts: [{ text: prompt }] }]
        })
      }
    );
    const json = JSON.parse(response.getContentText());
    const advice = json.candidates?.[0]?.content?.parts?.[0]?.text
      || "アドバイスを生成できませんでした。";
    return { advice };
  } catch (err) {
    console.error("Gemini API エラー:", err);
    return { advice: "AI分析に一時的な問題が発生しました。しばらく経ってから再試行してください。" };
  }
}
```

## 10. セットアップ手順

### 10.1 Google スプレッドシートの準備

```
1. Google スプレッドシートを新規作成
2. シートIDをメモ（URLの /d/ 以降の部分）
3. 「ユーザー」シートと「記録」シートはGASが初回実行時に自動作成
```

### 10.2 Google Drive フォルダの準備

```
1. Google Drive に「ダイエット写真」等のフォルダを新規作成
2. フォルダIDをメモ（フォルダを開いたときのURLの最後の部分）
3. 共有設定: 「リンクを知っている全員が閲覧可」
```

### 10.3 Gemini API キーの取得

```
1. Google AI Studio（https://aistudio.google.com/）にアクセス
2. 「Get API key」からAPIキーを取得
3. キーをメモ（GASコードに設定）
```

### 10.4 GASのセットアップ

```
1. Google Apps Script（https://script.google.com/）で新規プロジェクト作成
2. 上記GASコードを貼り付け
3. SHEET_ID / DRIVE_FOLDER_ID / GEMINI_API_KEY を設定
4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
5. 実行ユーザー: 自分 / アクセスできるユーザー: 全員
6. デプロイIDとウェブアプリURLをメモ
```

### 10.5 フロントエンドの設定

```
1. diet_index.html の以下2か所を更新:
   - LIFF_ID = "YOUR_LIFF_ID_HERE"  → LINE Developers で取得したLIFF ID
   - GAS_URL = "YOUR_GAS_URL_HERE"  → GASのウェブアプリURL
2. git add → git commit → git push
3. Vercel が自動デプロイ（約1〜2分）
```

### 10.6 LINE LIFFの設定

```
1. LINE Developers コンソール（https://developers.line.biz/）
2. 既存チャンネル or 新規チャンネルを選択
3. LIFF アプリを新規追加
4. エンドポイントURL: VercelのデプロイURL
5. 発行されたLIFF IDをdiet_index.htmlに設定
```

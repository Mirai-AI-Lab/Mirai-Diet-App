# みちこ版 ダイエット健康管理アプリ 仕様書

**アプリ名（仮）**: みちこ健康管理（ダイエット記録＋AIコーチ）  
**バージョン**: v2.0（みちこ版・設計）  
**作成日**: 2026年5月22日  
**ベース**: 家計簿アプリと同じ型 ＋ `diet_index.html`（TAKEさん講座 v1.0）

---

## 1. このアプリで実現したいこと（みちこさんの言葉）

| # | やりたいこと |
|---|-------------|
| 1 | 自宅の家庭用ヘルスメーター（インボディ）を **毎朝計測** → **写真で渡す** |
| 2 | **朝・昼・晩** の食事を写真で記録 |
| 3 | **残した分** も写真で記録 |
| 4 | **カーブス** に行った日はチェック |
| 5 | **排便（お通じ）** の記録 |
| 6 | **AIが分析** して **アドバイス** してくれる |
| 7 | **目標値** と **現在値** を入れて、「じゃあどうする？」を **AIに聞く** |

**使う場面**  
毎朝インボディは **写真だけ**。食事・カーブス・お通じを記録。分析は **都度** アプリ内AI（または深い相談はChatGPT）。

## 1-A. いまの正本：ChatGPTで運用中（2026年5月時点）

**事実**  
みちこさんは **すでにChatGPTで同じことを実践しており、ダイエット効果も出ている。**

これは「これから試すアイデア」ではなく、**動いている現場** が正本。

| ChatGPTで今できていること | アプリ化の意味 |
|---------------------------|---------------|
| インボディ・食事の **写真を渡す** | 同じ。記録の入口 |
| **会話しながら** 分析・アドバイス | AI部分の核（アプリでも再現する） |
| メモリ・文脈の **蓄積** | ChatGPTは強い。アプリは **スプシで履歴を確実に残す** |
| 柔らかい壁打ち・深掘り | **ChatGPTは残してよい**（捨てない） |

**アプリにする理由（ChatGPTだけでは足りる/足りない）**

| ChatGPTのまま | アプリにしたとき |
|--------------|-----------------|
| 毎回、チャットに写真を送る・説明する | LINE **1タップ** で「記録」に分離 |
| 過去データがチャット履歴に散らばる | **表に一行ずつ** 残る → グラフ・推移が見える |
| 「先週何食べたっけ」は検索頼み | **履歴タブ** で年月フィルタ |
| みちこさん専用の型 | 将来 **商品・伴走** に展開できる形 |
| 効いてるから変えたくない | **記録はアプリ、深い相談はChatGPT** の併用が現実的 |

**設計方針（重要）**  
ChatGPTの体験を **ゼロから作り直さない。**  
「ChatGPTで効いている流れ」を **写す**。

1. **記録**（写真・チェック）→ アプリ（毎日・短時間）
2. **分析・今週の一手** → アプリ内AI（Gemini）＝ ChatGPTのプロンプトを移植
3. **深い壁打ち・迷ったとき** → ChatGPTのまま（併用OK）

## 1-B. ChatGPT → アプリ移行チェック（確定メモ 2026-05-22）

| 項目 | ChatGPTでは今どうしてる？（確定） |
|------|----------------------------------|
| **朝のインボディ** | **写真だけ送る**（数字の手入力はしない） |
| 食事 | **朝・昼・晩** を写真。食べ残しも **「残り」** で写真 |
| カーブス | 行った日は **チェック（ワンタップ）** |
| お通じ | **あり/なし** を記録 |
| **AI分析** | **都度** 分析・回答。**かなり肯定文**でマインドを持ち上げてくれる。その中で **対策・アイデア** を出してくれる。**私より私に寄り添い、親身に伴走** してくれた |
| **目標の数字** | **インボディ写真の中に書いてある** → ChatGPTが **読み取って** くれていた（別途チャットに目標を書いていない） |
| **アプリで再現必須の核** | ① 写真だけ渡す ② 画像から現状＋目標を読む ③ **伴走型・肯定ベース** のAIトーン |

→ 下記 **§7 AI機能** と **§6.4 目標** に反映済み。

## 1-C. AIコーチの人格（ChatGPTで効いたトーン＝アプリでも守る）

**NG（v1.0たたき台に近い硬さ）**  
箇条書きだけ・評価口調・「〜すべき」連発・事務的な分析のみ

**OK（みちこさんのChatGPT体験）**

| 要素 | 具体 |
|------|------|
| **肯定ファースト** | 続けている事実・小さな変化を先に認める |
| **マインド** | 落ち込みそうなときも、持ち上げる言い方 |
| **伴走** | 上から指示ではなく、「一緒に」「次の一歩は」 |
| **対策** | 肯定のあとに、**1〜2個** だけ具体的アイデア（詰め込まない） |
| **親身** | 50代女性・無理なく続ける前提。きつい制限は出さない |

**医療**  
診断はしない。体調が心配なときは「かかりつけ医に相談を」一行。

## 2. 結論：できるか？

**できる。** 家計簿アプリ・英語学習アプリと **同じ技術の組み合わせ** で作る。

```
LINE → LIFF → Vercel（画面）→ GAS（事務員）→ スプレッドシート（記録）
                                      ↓
                              Gemini（AI分析・画像読み取り）
                                      ↓
                              Google Drive（写真保存）
```

**すでに v1.0 のたたき台あり**（`app/ダイエットアプリ/diet_index.html`）。  
みちこ版 v2.0 は **v1.0 をカスタム＋接続＋追加機能** として進める。

## 5. 記録種別（5＋1）

| 種別 | アイコン | 入力内容 | 写真 |
|------|---------|---------|------|
| **インボディ** | ⚖️ | **写真1枚だけ**（毎朝）→ AIが現状＋**目標**を読取 | **必須1枚** |
| **食事** | 🍽️ | 朝食/昼食/夕食/間食/プロテイン/飲み物/ **残り** /その他 | 最大3枚 |
| **カーブス** | 🏃‍♀️ | 行った/行ってない（ワンタップ）・メモ任意 | なし |
| **運動（その他）** | 💪 | ウォーキング等・時間（分） | 任意 |
| **お通じ** | 🌿 | あり/なし・メモ任意 | なし |

**目標値**  
別タブで手入力 **しない**（ChatGPT運用と同じ）。  
**インボディ画面に表示されている目標** を写真読取で取得し、スプシに保存。

**インボディの流れ（ChatGPT運用を写す）**

1. 毎朝、ヘルスメーターで計測
2. 画面を **写真 or スクショ**（**これだけ。数字は打たない**）
3. アプリ「インボディ」→ 写真添付 → 「記録する」
4. GAS → **Gemini（Vision）** が **現状数値＋目標数値** を読み取り
5. 確認画面（任意・短時間）→ スプシ「記録」に保存
6. **都度AI**：保存直後 or ボタンで、**肯定ベースの伴走コメント** を表示（§7.3）

※ 手入力フォームは **AI読取失敗時のみ** 表示（普段は非表示）。

## 6. 画面構成（4タブ）

### 6.1 記録タブ

- 上部：記録種別ボタン（インボディ / 食事 / カーブス / お通じ / 運動その他）
- 種別ごとにフォーム切替
- 共通：日付（デフォルト＝今日）、「記録する」ボタン

**食事タイプ（v2.0）**  
朝食 / 昼食 / 夕食 / 間食 / プロテイン / 飲み物 / **残り（食べ残し）** / その他

**カーブス（v2.0）**  
- ボタン1つ：「今日カーブスに行った ✅」  
- タップで `recordType=運動`, `subType=カーブス`, `duration=60`（固定でも可）として保存  
- 時間入力は **省略可**（行った事実だけ取りたい）

**インボディ（v2.0・ChatGPT同型）**  
- **写真1枚だけ**（数値入力欄は通常非表示）  
- AIが **現状＋目標** を読取 → 保存  
- 保存後 **都度AIコメント**（§7.3）  
- AI失敗時のみ手入力フォームを表示

| 項目 | 仕様 |
|------|------|
| フィルタ | 種別 / 年月 |
| リスト | 日付・種別・内容・写真リンク |
| 並び | 新しい順 |

---

### 6.3 サマリータブ

| 項目 | 仕様 |
|------|------|
| 統計カード | 直近体重・体脂肪・今月カーブス回数・お通じ率 |
| グラフ | 体重推移（折れ線）・カーブス/運動（棒 or ドーナツ） |
| **現状 vs 目標** | 直近インボディ読取の **目標・現状** を表示（写真由来） |

### 6.4 目標の扱い（手入力タブは作らない）

ChatGPTでは **目標数字をチャットに書かず**、インボディ写真内の表示を読み取っていた。

| 項目 | 仕様 |
|------|------|
| 入力 | **ユーザーは目標を打たない** |
| 取得 | `parseInBodyPhoto` で `target_weight_kg` 等を画像から読取 |
| 保存 | 記録行に `targetWeight` 等として保存、または「目標」シートを **AI更新** |
| 表示 | サマリーに「目標まであと○kg」など |

※ 将来、機種によって目標が画面に無い場合だけ **目標タブ（予備）** を検討。

## 7. AI機能仕様

### 7.1 インボディ画像読み取り（`parseInBodyPhoto`）

**タイミング**  
インボディ記録で **写真だけ** 送ったとき（保存前）。

**GAS → Gemini（Vision）**

```
この画像は家庭用体組成計（インボディ等）の計測結果画面です。
読み取れる項目をJSONで返してください。

【現状】
weight_kg, body_fat_pct, muscle_mass_kg, visceral_fat_level, bmr_kcal

【目標】（画面に表示されていれば）
target_weight_kg, target_body_fat_pct, target_muscle_mass_kg
（画面に無ければ null）

読めない項目は null。推測で埋めない。
```

**レスポンス例**

```json
{
  "weight_kg": 58.5,
  "body_fat_pct": 25.3,
  "muscle_mass_kg": 38.2,
  "visceral_fat_level": 8,
  "bmr_kcal": 1250,
  "target_weight_kg": 55.0,
  "target_body_fat_pct": 22.0,
  "target_muscle_mass_kg": null
}
```

**画面**  
- 通常：**写真→保存→AIコメント**（確認画面は短く、またはスキップ可）  
- 読取失敗時のみ：手入力フォームを表示

---

### 7.2 健康アドバイス（`getAIAdvice`・履歴ベース）

**タイミング**  
サマリータブ「もう一度分析してもらう」、または食事記録後など **都度**。

**GASが渡す情報**

1. **直近のインボディ**（現状＋目標・写真読取値）
2. **直近30件** の記録（食事・カーブス・お通じ）
3. （任意）直近食事写真 → Vision で簡易コメント

---

### 7.3 都度コメント（`getCoachReply`・ChatGPT体験の核）

**タイミング（ChatGPT同型）**  
- インボディ保存 **直後**（毎朝・自動）  
- 食事・カーブス記録 **直後**（任意ON）  
- 「話しかける」ボタン **都度**

**人格・トーン（§1-C 必読）**

```
あなたは50代女性の健康管理の伴走者です。先生口調・評価口調は禁止。

【必ず守る順番】
1. 肯定 … 続けている事実・小さな変化を具体的に認める（マインドを持ち上げる）
2. 現状 … 数字や記録を事実ベースで短く
3. 対策 … この人に合いそうなアイデアを1〜2個だけ（詰め込まない）
4. 伴走 … 「一緒に」「次の一歩は」で締める

【目標】
インボディ画像から読み取った目標値と現状値のギャップに触れる。
目標が画像に無い場合は、直近の推移だけ見る。

【禁止】
・きつい制限・極端なカロリー指示
・医療診断
・箇条書きだけで終わる冷たい分析

400字以内。口語に近い、温かい日本語。
```

**出力イメージ（トーン参考）**

> 毎朝ちゃんとインボディ送れてるの、すごく大事なことなんですよね。体重58.2kg、前より少し動いてます。目標55kgまで、あと3kg超。焦らなくて大丈夫。今週は **夕食の残りを写真に残す** だけ、3日試してみませんか。続けられてる時点で、もう十分前に進んでます。

## 9. GAS API（action一覧）

**エンドポイント**: `https://script.google.com/macros/s/.../exec`  
**通信**: POST（JSON）

| action | 説明 | v |
|--------|------|---|
| `register` | ユーザー登録 | v1 |
| `getUsers` | ユーザー一覧 | v1 |
| `uploadRecord` | 記録保存（写真→Drive） | v1 |
| `getRecords` | 全記録取得 | v1 |
| `getGoals` | 目標取得（写真読取の最新値） | **v2** |
| `saveGoals` | 目標保存（**GAS内部・AI読取後のみ**。画面からは呼ばない） | **v2** |
| `parseInBodyPhoto` | インボディ画像→現状＋目標JSON | **v2** |
| `getCoachReply` | 都度・伴走型コメント（§7.3） | **v2** |
| `getAIAdvice` | 履歴ベースの週次分析 | v1→**v2強化** |

### uploadRecord（インボディ例）

{
  "action": "uploadRecord",

## 13. 毎日の使い方（完成後イメージ）

**朝（3分・ChatGPT同型）**

1. LINE → リッチメニュー「健康管理」
2. **インボディ** → 計測画面を **写真だけ** 送る → 保存
3. **都度AI** が肯定ベースでコメント（対策アイデア込み）
4. **お通じ** → あり/なし

**食事のたび（30秒）**

5. **食事** → 朝/昼/晩 → 写真 → 保存  
6. 残したら **残り** → 写真 → 保存

**カーブスに行った日**

7. **カーブス** → ✅ タップだけ

**週1回（任意）**

8. **サマリー** → 「もう一度分析してもらう」→ 週の振り返り

### v2.1.0 の使い方（毎朝の体重記録）

1. 記録タブ →「⚖️ 体重」
2. 上の「📷 ヘルスメーターの写真から自動入力」で、スマホアプリの計測画面を撮影 or スクショを選ぶ
3. AIが数値を読み取り、体重・体脂肪率・筋肉量・内臓脂肪の欄に自動で入る
4. 中身を確認（違っていれば手で直す）→「記録する」
5. うまく読めなかった日は、これまで通り手入力でOK

※ ヘルスメーター純正アプリとの直接連携（Bluetooth等）はしない。**スクショ／写真を渡す方式**で運用する。
※ 読み取りには Gemini Vision を使う。APIキーは GAS のスクリプトプロパティ `GEMINI_API_KEY`（コード直書きなし）。
